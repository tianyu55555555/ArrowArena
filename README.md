# AI 娘像素大乱斗（Godot 4.7）

> **免责声明**：本项目为**非官方免费公益同人二创作品**，仅用于游戏开发学习、AI 公益科普与亲友联机娱乐，与文中提及的各 AI 机构无任何官方关联，**严禁用于任何商业用途**。

一款基于 Godot 4.7（GDScript + GL Compatibility）制作的像素风双模式动作竞技小游戏，集成了 **6 位 AI 大模型二次元角色**、**伪 Live2D 互动大厅立绘**、**32×32 程序化像素精灵与 8-bit 音乐音效**、**局域网联机（ENet）** 以及 **AI 公益科普图鉴馆**。

## 核心玩法

- **⚔ 五宫格 PVP 决斗场（自由乱斗 FFA / 2v2v2v2 组队）**
  - 中央大型决斗场 + 边四格特色房间（北·算力超频室 / 南·脱战缓修站 / 西·极速风道与移动电锯陷阱 / 东·脏数据野区击杀爆 Token 与血药）。
  - 室内大量金属薄墙掩体，支持「量子穿墙」与「穿墙弹道」词条。
  - **四角增益符文祭坛**：随机刷新 6 种符文（减伤 / 吸血 / 生命恢复 / 减技能 CD / 临时血量 / 子弹变大），持续 15 秒、60 秒刷新。
  - **中央 Mid Boss（算力霸主）**：1:30 首次降临、后续每 3 分钟刷新，斩杀者独享 **30 秒全 6 项神级增益 + 1 次复活甲**。
  - **最后 60 秒算力坍缩缩圈**：毒圈向中央决斗场收缩，倒逼终局大决战。
- **🌊 算力潮汐 PVE（吸血鬼幸存者 · 4 档难度 + 双人合作无尽）**
  - 100+ 同屏像素怪潮与多阶段 Boss、6 位 AI 支援副武 + 2 阶 MoE 混合专家协同、6 把本命武器神话超武进化。
  - 本地持久化存档（`user://save.json`）：折算算力点永久升级局外天赋树。
- **🌐 局域网 / 虚拟局域网联机**
  - 内置 ENet 联机（UDP `7777`）与局域网自动扫描（UDP `7778`），支持 PVE 双人无尽合作（倒地互救）、PVP 乱斗与 2v2v2v2（可选补齐 AI 人机）。
  - 战内按 **`1 / 2 / 3 / 4`** 或 **`T`** 发送角色专属热梗语音气泡，全员实时可见！

## 操作说明
- **移动**：`WASD` / 方向键（触屏左半屏虚拟摇杆）
- **攻击**：鼠标指向 + 按住左键（触屏右半屏滑动；PVE 模式默认开启辅助自动开火，手动瞄准随时覆盖）
- **大招**：`Space` / `E` / 鼠标右键
- **热梗气泡**：`1` / `2` / `3` / `4` 或 `T`（非选卡界面）
- **升级选卡**：`1` / `2` / `3`，按 `R` 刷新词条；`ESC` 暂停与查看实时 Build

## 本地运行与打包
1. 使用 **Godot 4.7+** 导入本目录的 `project.godot`，按 `F5` 运行。
2. 如需打包独立 Windows 绿色版 `.exe`，请确保已安装对应版本的 Windows 导出模板，并在编辑器选择 `项目 → 导出 → Windows Desktop`。
